\begin{abstract}\noindent
\textbf{The Reggae Shark Protocol (v1.2.0)} is a verifiable execution kernel and multi-cloud AI gateway that binds agent prompt dispatches to four mathematical and cryptographic verification layers: (1) an append-only, SHA-256 hash-chained \textbf{IntentSeal Verifiable Research Kernel (VRK v0.3.1)} ledger enforcing the \texttt{intentseal-vrk-claim-v2} schema with an $N$-way commutative, associative, and idempotent Merkle-DAG join-semilattice for distributed split-brain reconciliation; (1B) a thread-synchronized \textbf{Request-Lifecycle Typestate and Worker-Epoch Isolation} state machine (\texttt{TypestateLifecycle.lean}, 12 zero-\texttt{sorry} theorems) that rules out partial-initialization payload dereferencing, cross-epoch worker-slot reads, and free-threaded (PEP 703) lock-order races within the modelled state machine; (2) a per-tenant isolated \textbf{4D Soft-Wall ODE Cognitive Dynamics Governor} $(\gamma, H_{\text{obs}}, \dot{I}, \Psi)$ backed by 17 Lean 4 4D boundary theorems (\texttt{ExistenceVerification.lean}), 9 3D soft-wall theorems (\texttt{BoundaryVerification.lean}), and a subnormal-safe Patankar--Euler interval integrator; and (3) a \textbf{Bandlimited Low-Rank Spectral Context Memory (LRSC)} operator ($M=99, K=11$) with dual compressed/uncompressed SHA-256 sealing and an exact downstream attention Lipschitz error bound.
\end{abstract}

\begin{align}
  \frac{d\gamma}{dt} &= a \dot{I} \mathcal{E}_{\text{avail}}\left(1 - \frac{\gamma}{\gamma_{\max}}\right) - b\gamma, \label{eq:gamma}\\
  \frac{dH_{\text{obs}}}{dt} &= c\gamma\left(H_{\max} - H_{\text{obs}}\right) - \dot{I}_{\text{erase}}\tanh\!\left(\frac{H_{\text{obs}}}{\epsilon_H}\right), \label{eq:hobs}\\
  \frac{d\dot{I}}{dt} &= e\tanh\!\left(\frac{\dot{I}}{\epsilon_I}\right)\frac{dH_{\text{obs}}}{dt} + f\mathcal{P}_{\text{eff}}(\gamma, \Psi) - g\dot{I}, \label{eq:idot}\\
